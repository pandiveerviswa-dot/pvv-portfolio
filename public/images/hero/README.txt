===================================================================
PORTRAIT PHOTOGRAPH PLACEMENT INSTRUCTIONS
===================================================================

To integrate your real portrait into the hero section:

1. Place your photo file in this exact directory:
   public/images/hero/portrait.jpg
   (or portrait.png)

2. The website will immediately load your photo inside the art-directed
   editorial frame with:
   - High-contrast monochrome rendering
   - Subtle acid-lime ambient rim lighting
   - Coordinated 3D scroll parallax & depth

3. If no file is placed here, the system gracefully falls back to the
   minimalist editorial placeholder (hero.svg).
